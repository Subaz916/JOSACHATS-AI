Documentation

JOSA CHATS runs on Node.js, Supabase, and Safepay sandbox.

Quickstart

npm install
cp .env.example .env
supabase db push
npm start

Supabase

Enable Google provider. Set the site URL and redirect URL to your domain. Create storage buckets knowledge-files, agent-assets, and audio. Apply all migrations in supabase/migrations and run supabase/seed.sql.

Environment

Use Groq free tier with AI_PROVIDER=openai-compatible, AI_API_URL=https://api.groq.com/openai/v1, and AI_MODEL=llama-3.1-8b-instant. Add your Groq key as AI_API_KEY. Keep TTS_API_URL, TTS_API_KEY, STT_API_URL, and STT_API_KEY blank to use free browser/offline device voices where available.

Safepay sandbox

Use sandbox keys and host sandbox.api.getsafepay.com. Set the webhook URL to /api/webhooks/safepay. Only flip SAFEPAY_PRODUCTION_ENABLED after sandbox verification.

Deployment

Serve /frontend as static files behind the Express app. Use HTTPS. Set CORS_ORIGINS for widget host domains. Keep service-role keys server-side only.
